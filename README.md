# Game Tournament

Учебный проект: класс управления турниром игроков на Java.

## Описание

Проект моделирует турнир, в котором игроки соревнуются друг с другом в силе. Каждый игрок описывается дата-классом `Player`, а сам турнир управляется классом `Game`.



## Классы

### `Player`

Дата-класс, описывающий игрока.

| Поле       | Тип      | Описание            |
|------------|----------|---------------------|
| `id`       | `int`    | Уникальный идентификатор |
| `name`     | `String` | Имя игрока          |
| `strength` | `int`    | Сила игрока         |

### `NotRegisteredException`

Исключение (наследник `RuntimeException`), выбрасывается при попытке провести бой с незарегистрированным игроком.

### `Game`

Класс, управляющий турниром.

#### Методы

| Метод | Описание |
|---|---|
| `void register(Player player)` | Регистрирует игрока в турнире. Незарегистрированный игрок не может участвовать в боях. |
| `int round(String playerName1, String playerName2)` | Проводит бой между двумя игроками по их именам. |

#### Возвращаемые значения `round`

| Значение | Ситуация |
|---|---|
| `0` | Ничья (силы равны) |
| `1` | Победил первый игрок |
| `2` | Победил второй игрок |

Если хотя бы один из игроков не зарегистрирован — выбрасывается `NotRegisteredException`.



## Сборка и запуск тестов

### Maven

```bash
  mvn clean test
```


## Тестирование

Тесты написаны на JUnit 5 и покрывают 100% веток класса `Game`:

- победа первого игрока;
- победа второго игрока;
- ничья при равной силе;
- исключение при незарегистрированном первом игроке;
- исключение при незарегистрированном втором игроке;
- исключение при обоих незарегистрированных игроках;

## Покрытие тестов (JaCoCo)

Проект использует [JaCoCo](https://www.jacoco.org/jacoco/) для измерения покрытия кода тестами. Плагин настроен в `pom.xml` и автоматически собирает данные во время выполнения тестов.

### Запуск с покрытием

```bash
  mvn clean verify
```

## CI

Проект собирается и тестируется в GitHub Actions при каждом push и pull request в ветку `main`.

## Ветки

- `main` — стабильная версия (текущая реализация на `List`).
- `fast` — экспериментальная ветка с заменой `List` на `HashMap` для O(1)-поиска игрока по имени.
